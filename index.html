Odoo Hackathon Flagship Project

Unified, AI-Powered Smart Travel ERP Workspace

Transforming fragmented travel planning into an integrated Odoo ERP ecosystem—from automated day-wise itineraries & AI optimization to real-time expense equalizers.

View Codebase Explore Modules

Core Platform Features

Built with custom Odoo ORM models, business logic engines, and REST endpoints.

Smart Trip Workspace

Manage destinations, travel styles, duration, and traveler access controls directly within custom Odoo models (gt.trip).

Day-wise Itinerary Builder

Structured daily activity schedules with category tags, cost tracking, ratings, and weather-aware activity flags.

Group Debt Equalizer

Integrated minimum-cash-flow algorithm (_compute_debt_settlements) calculating fair member balance settlements.

"What-If?" Trip Optimizer

Simulate budget changes, rain mode activity swaps, and duration upgrades with one-click automated optimization.

AI Gateway & REST API

Clean REST/JSON endpoints (/api/v1/trips) exposing trip workflows to AI recommendation systems.

Expense Dashboards

Dynamic Odoo graph and pivot views providing real-time budget category insights and expense tracking.

Odoo Module Architecture

Engineered with modular Odoo security ACLs, ORM business logic, dynamic XML views, and external REST controller integration.

  • Python 3 & Odoo ORM Models
  • RESTful JSON-RPC API Controller
  • Modular Security ACLs & Access Rules
